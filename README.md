# TOURGUIDE AI — Cinematic Autonomous Travel Planning & Booking Platform

TOURGUIDE AI is a next-generation luxury AI-powered travel planner featuring live route navigation, fleet selection, gourmet highway stops, sanctuary stays, multi-tenant partner admin portals, and an executive command center.

## Features

- **Autonomous AI Concierge**: Real-time travel planning, live weather integration, and custom route generation.
- **Dynamic Fleet & Sanctuary Booking**: Sedans, Executive SUVs, Luxury Charters, and Hotel Suites.
- **Itemized Per-Person Food Calculations**: Clear pricing breakdown calculated per person for highway dhabas & gourmet stops.
- **Multi-Tenant Partner Dashboards**: Isolated admin control for Hotel Owners, Travel Agencies, and Platform Admins.
- **Vercel & Production Ready**: Pre-configured SPA routing and server bundling.

## Run Locally

**Prerequisites:** Node.js (v18+)

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Configure Environment Variables**:
   Create a `.env` file and set:
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   ```

3. **Start Development Server**:
   ```bash
   npm run dev
   ```

4. Open `http://localhost:3000` in your browser.
